## 如何运行

运行入口为 Zotero 桌面端的 **工具 → 开发者 → Run JavaScript（运行 JavaScript）**。这些脚本使用 Zotero 本地客户端 API，不是网页控制台脚本或独立 Node.js 程序，也不是 Zotero Web API 示例。

运行前请阅读[中文运行指南](docs/RUNNING.zh-CN.md)和[注意事项](docs/SAFETY.md)。会修改文献库的脚本应先做好独立备份，再在可丢弃的 Zotero 测试配置中以少量数据验证。同步不能代替备份。

## 参与完善

每个工具应保持独立可运行，并说明作用范围、输入、输出、对文献库的修改和外部请求。测试使用有代表性的合成数据，覆盖边界情况。不要提交个人文献库、导出的笔记、凭据、私人文件路径或有版权的 PDF 作为测试数据。修复原脚本时，应明确记录行为变化。

[批量提取交接提示词](prompts/extract-original-scripts.md)用于取得完整原文后的机械整理；API 核对由维护者另行完成。该提示词不允许用新脚本补齐缺失原文。
