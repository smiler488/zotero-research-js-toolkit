# 快速上手

[English](getting-started.md) | **简体中文** · [返回 README](../README.zh-CN.md)

## 1. 环境要求

- Zotero 10（10.0.x）桌面版，支持 Windows、macOS 与 Linux。多数脚本也可在 Zotero 7–9 中运行，详见 [compatibility.md](compatibility.md)。
- 无需安装插件，也无需联网。

## 2. 先备份（写入类脚本）

脚本 03、04、05 可能修改条目字段或添加标签。首次使用前：

1. 关闭 Zotero。
2. 将 Zotero 数据目录（位置见 **设置 → 高级 → 文件和文件夹 → 数据存储位置**）复制到安全位置。
3. 重新打开 Zotero。

只读脚本（01、02、06–14）无需备份。

## 3. 运行脚本

1. **选中条目。** 点击某个分类、保存的检索或文献库，在中间窗格中选择条目；Ctrl/Cmd+A 可全选当前视图。脚本只处理“常规条目”（期刊论文、图书等），独立笔记与附件会被忽略，回收站中的条目会被跳过。Zotero 10 支持同时选择多个分类，脚本处理的是条目列表中被选中的条目。
2. **打开运行器。** **工具 → 开发者 → Run JavaScript**。
3. **粘贴。** 打开本仓库中的 `.js` 文件（在 GitHub 上：点击文件 → *Raw* → 全选 → 复制），粘贴**完整文件**，包括头部注释。
4. **运行。** 点击 **Run** 或按 Ctrl/Cmd+R。每个脚本都以 `return await main();` 结尾，Zotero 会将其作为异步函数运行。如界面中有 **Run as async function** 复选框，请保持勾选。
5. **查看结果。** 结果显示在右侧窗格；较长的报告在窗格中会被截断，但完整内容已复制到剪贴板。

## 4. 参数配置

每个脚本顶部标有 `Config / 配置` 的区域即为可修改参数：

| 参数 | 适用脚本 | 含义 |
|---|---|---|
| `LANG` | 全部 | `"zh"`（默认）或 `"en"` 输出语言 |
| `PREVIEW_ONLY` | 03、04 | `true` 仅报告；`false` 确认后写入 |
| `RULES` | 04 | 正则 → 标签规则（不要使用 g 标志） |
| `MAX_ITEMS`、`MAX_ABSTRACT_CHARS` | 06 | 提示词规模限制 |
| `KEYWORDS`、`CONTEXT`、`MAX_HITS` | 12 | 关键词上下文检索 |
| `GROUP_A`、`GROUP_B`、`EXCLUDE_TITLE`、`WHOLE_WORD` | 13 | 初筛规则 |
| `TOPICS`、`WHOLE_WORD` | 14 | 主题 → 关键词列表 |
| `LOOSE` | 11 | 比较标签时将 `-`/`_` 视为空格 |

[`examples/`](../examples/) 中提供了面向作物学、遥感与表型研究的关键词配置示例。

## 5. 写入保护机制

对于 03（`PREVIEW_ONLY = false` 时）、04（`PREVIEW_ONLY = false` 时）与 05：

1. 脚本先计算全部修改，并跳过只读文献库（订阅源、无编辑权限的群组）中的条目。
2. 将制表符分隔的**回滚记录**（文献库 ID、条目 Key、字段、修改前值、修改后值）复制到剪贴板；如复制失败，脚本直接停止且不写入。
3. 弹出对话框展示部分修改内容。**默认按钮为“取消”**，按 Esc 或关闭对话框同样视为取消；“应用”按钮延时启用。
4. 只有点击“应用”后才会保存，且所有修改在同一数据库事务中完成。

点击“应用”前，请先将回滚记录粘贴到文本文件中保存。如需撤回 DOI 修改，可按条目 Key 检索并填回原值；如需撤回标签，在标签选择器中删除该标签即可。

## 6. 典型工作流程

- **学位论文或投稿参考文献整理：** 01 或 08 → 补全字段 → 03（先预览再写入）→ 02 → 在“重复条目”中合并。
- **系统综述初筛：** 将检索结果导入一个分类 → 13 → 在电子表格中筛选 → 用 04 为筛选结论打标签（修改 `RULES`）→ 用 14 绘制年度主题趋势图。
- **建模参数提取：** 07（确认 PDF 已在本地）→ 用 12 检索参数关键词（如 `Vcmax`、`LAI`、`leaf angle`、`nitrogen rate`）→ 对照 PDF 核实数值。
- **阅读笔记整理：** 在 Zotero 阅读器中批注 → 09 → 粘贴到 Markdown/Obsidian；用 10 生成概览表；用 06 借助大模型分析研究空白。

## 7. 常见问题

| 现象 | 处理方法 |
|---|---|
| `SyntaxError: return not in function` | 脚本以同步模式运行。请确认粘贴了完整文件（其中包含 `await`），或勾选 *Run as async function*。 |
| 提示“请先选择文献” | 在条目列表中选中常规条目，而不仅是附件。 |
| 脚本 12 报告“无文本” | PDF 为扫描件或未建立索引：右键 PDF → *重建索引*，并检查 **设置 → 搜索**。 |
| 脚本 07 报告文件“本地不可用” | 双击打开一次附件以触发下载，或重新链接已移动的文件。 |
| 剪贴板中没有内容 | 部分 Linux 桌面需要剪贴板管理器，可直接从结果窗格复制。 |
| 无法解释的错误 | 打开 **工具 → 开发者 → Error Console**，将输出连同 Zotero 版本号（帮助 → 关于 Zotero）提交到 GitHub Issue。 |
